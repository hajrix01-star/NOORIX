# React Query keys (Noorix)

## المصدر الواحد للمفاتيح

- تعريف المفاتيح والبادئات في **`src/services/queryKeys/`** (مصانع مثل `invoiceKeys.list`, `vaultKeys.root`, …).
- في الاستعلامات استخدم هذه المصانع بدل تكرار السلاسل يدويًا في `queryKey`.

## الإبطال المالي المركزي

- **`src/utils/queryInvalidation.ts`** (`invalidateOnFinancialMutation`) يجب أن يبني قائمة البادئات من دوال **`*Root()`** (أو ما يعادلها) في نفس المجلد، وليس من مصفوفات حرفية مكررة، ما دامت الدالة تُرجع **نفس** بادئة المفتاح المستخدمة في الاستعلامات.
- الهدف: أي تغيير في اسم المقطع الأول لمفتاح استعلام يحدث في مكان واحد فقط.
- عند إضافة استعلام جديد يتأثر بالعمليات المالية، أضف بادئة الإبطال المناسبة عبر المصنع في **`queryKeys`** ثم أدرج الاستدعاء في **`FINANCIAL_QUERY_PREFIXES`** دون تغيير ترتيب الإبطال إلا إذا كان مقصودًا توثيقًا.
