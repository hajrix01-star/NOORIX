# تقرير انتقال الطلبات القديم إلى طلبات V4

التاريخ: 2026-08-02
النطاق: جميع الشركات المتاحة في لوحة المالك
الحالة: الترحيل التشغيلي مكتمل، والمطابقات الحرجة ناجحة

## ضوابط التنفيذ

- تم تفريغ بيانات الاختبار في V4 واستبدالها داخل معاملة PostgreSQL ذرية لكل شركة على حدة.
- كل تشغيل محمي ببصمة للمصدر وقفل للشركة؛ أي اختلاف أو خطأ يؤدي إلى تراجع كامل بلا بيانات جزئية.
- إنشاء أرصدة الافتتاح مر عبر خدمة دفتر المخزون المركزية، وحركات العهدة مرت عبر خدمة العهدة المركزية.
- بوابات الاعتماد داخل المعاملة: عدد طلبات الشراء، إجمالي الشراء، عدد التسجيلات، إجمالي التسجيلات، رصيد العهدة، كمية المخزون، قيمة المخزون، وعدد روابط الترحيل.
- عُزلت المعرفات الحتمية حسب الشركة لمنع أي تصادم بين الشركات.
- لم تُستورد أي وحدة صنف لا تملك مسار تحويل صالحاً إلى وحدة النواة؛ لذلك بقيت معادلات المخزون مركزية وقابلة للصيانة.

## ملاحظات جودة المصدر

- في ARZ توجد 190 بطاقة بيع بلا رسبي صالحة في المصدر القديم. نُقلت البطاقات والتسجيلات التاريخية بلا اختراع مكونات أو خصومات مخزون غير حقيقية، وأصبحت أصناف بيع غير متتبعة مخزونياً إلى أن تُبنى رسبي معتمدة لها.
- تم إسقاط تغليفات قديمة غير مرتبطة بمعادلة تحويل صحيحة من خيارات الصنف في V4. لم تُحذف الوحدات المركزية، وإنما مُنع ربطها بالصنف حتى تُعرّف معادلة صحيحة.
- بعد هذا التنظيف أصبحت نتيجة فحص جودة V4 في ARZ والمعلم الشامي: `جاهز`، ولا توجد أخطاء دفتر أو عهدة أو تكلفة مستند.

## إزالة طلبات 2 / V3

تم إعداد إزالة النواة V3 من الواجهة والخادم والعقود والمسارات والأذونات والجداول. ترقية قاعدة البيانات تنقل تلقائياً أي صلاحية V3 موجودة في الأدوار إلى صلاحية V4 المناظرة قبل حذف مفاتيح وجداول V3. يبقى قسم الطلبات القديم وبياناته دون تغيير كمصدر رجوع مستقل.
