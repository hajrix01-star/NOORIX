# شفافية جودة بيانات المخزون

## الهدف

يعرض مسار `GET /api/v1/orders/inventory-data-quality` جودة مصادر رصيد المخزون للشركة الحالية. المسار للقراءة فقط، ولا يرحل أو يعدل أو يحذف بيانات `ShishaInventory` القديمة.

تظهر النتيجة داخل `InventoryCostTab` بجانب الرصيد حتى يعرف المستخدم إن كان الحساب يعتمد snapshots تاريخية ثابتة أو تقديرًا بديلًا.

## عقد الاستجابة

- `status`: إما `verified` أو `needs_review`.
- `checkedAt`: وقت تنفيذ الفحص بصيغة ISO.
- `legacy.shisha*Rows`: عدد صفوف الإعدادات والحركات والجرد في جداول Shisha السابقة للشركة.
- `legacy.purchaseItemsWithoutSnapshot`: بنود المشتريات النشطة التي لا تحتوي `inventory_base_quantity_snapshot` ويعيد النظام حسابها من الكمية والوحدة والتحويل المحفوظ أو الحالي.
- `estimated.saleItemsFromCurrentRecipe`: بنود المبيعات المرسلة التي لا تحتوي snapshot استهلاك صالح، ولذلك يقدر استهلاكها من الوصفة الحالية.
- `snapshots.purchases`: إجمالي بنود المشتريات النشطة وعدد الموثق والمفقود منها.
- `snapshots.consumption`: إجمالي بنود المبيعات المرسلة وعدد snapshots الموثقة والمفقودة وغير الصالحة.

## قاعدة الحالة

تكون الحالة `verified` فقط عندما تتحقق الشروط كلها:

1. لا توجد صفوف في جداول Shisha القديمة للشركة.
2. كل بنود المشتريات النشطة تحتوي snapshot كمية مخزنية.
3. كل بنود المبيعات المرسلة تحتوي snapshot استهلاك صالح بالإصدار `1` ومكونات صالحة.

أي مخالفة تجعل الحالة `needs_review`. هذه الحالة تقيس اكتمال مصدر الإسقاط وقابليته لإعادة الإنتاج، وليست إقرارًا محاسبيًا بأن الكمية الفعلية صحيحة.

## حدود البيانات

- المشتريات الملغاة والمبيعات غير المرسلة لا تدخل الفحص، اتساقًا مع رصيد المخزون الحالي.
- صلاحية snapshot الاستهلاك تستخدم helper SQL نفسه الذي يستخدمه `OrdersInventoryService`؛ لا يوجد تعريف موازٍ قد يعطي نتيجة مختلفة.
- صفوف Shisha القديمة تعد للشفافية فقط ولا تدخل تلقائيًا في الرصيد العام.
- لا توجد كتابة إلى الجداول القديمة، ولا يتضمن هذا الإغلاق `DROP` أو تعديل migrations السابقة.

## تحقق التشغيل

- اختبارات backend تثبت حالتي `verified` و`needs_review` وتفصيل العدادات.
- اختبار عقد الواجهة يثبت عنوان endpoint وتمرير `companyId`.
- اختبار لوحة العرض يثبت ظهور مصادر legacy والتقدير والـsnapshots المفقودة وغير الصالحة وحالة الخطأ القابلة لإعادة المحاولة.
