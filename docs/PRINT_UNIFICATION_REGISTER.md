# سجل توحيد الطباعة

تاريخ التحديث: 2026-07-09

## الهدف

كل طباعة في Noorix يجب أن تمر عبر قالب مركزي واحد يحافظ على:

- اسم الشركة في رأس الطباعة.
- شعار الشركة عند توفره.
- اتجاه اللغة الصحيح.
- رأس جدول موحد.
- محاذاة رقمية موحدة.
- تذييل وتاريخ طباعة موحد.
- أنواع TypeScript نظيفة بدون `any`.

## قاعدة التنفيذ المقترحة

أي أمر طباعة جديد أو قائم يجب أن يستخدم واحداً من المسارين فقط:

| الحالة | المسار المسموح |
|---|---|
| طباعة أو PDF في نافذة مستقلة | `PrintPreviewModal` |
| معاينة داخل مودال أو iframe | `buildPrintDocumentHtml` |
| جدول مطبوع بسيط | `buildPrintHtmlTable` داخل القالب المركزي |
| مستند قانوني/مالي خاص | يستخدم القالب المركزي، ويضيف CSS خاص معزول |

## قرار PDF

تصدير PDF للتقارير والجداول ليس قالباً مستقلاً. القرار المعتمد:

| الزر | السلوك |
|---|---|
| طباعة | يفتح معاينة المستند ثم أمر الطباعة |
| PDF | يفتح نفس معاينة المستند، والحفظ يتم من أمر الطباعة عبر Save as PDF |
| طباعة / حفظ PDF | زر واحد داخل المعاينة يستدعي `window.print()` من القالب المركزي |

الاستثناء الوحيد هو PDF نظامي ثابت يحتاج توليد ملف حقيقي للأرشفة أو التوقيع أو QR. هذا النوع يوثق كاستثناء ولا يعيد بناء هوية الطباعة من الصفر.

## تعريف الإغلاق النهائي

لا تعتبر الطباعة موحدة بالكامل حتى تتحقق الشروط التالية:

- لا يوجد `window.print` خارج `printUtils.ts` إلا في استثناء موثق.
- لا يوجد `window.open` للطباعة خارج `printUtils.ts`.
- كل `PrintPreviewModal` يمرر اسم الشركة وشعارها عندما تكون الشركة معروفة.
- كل مستند مخصص يمر من `buildPrintDocumentHtml` أو يملك سبب حماية مكتوب.
- فحص `check:print-export-governance` يرصد المخالفات الجديدة تلقائياً.

## تحديث 2026-07-09 - توحيد تجربة المعاينة

تم اعتماد تجربة مركزية جديدة للطباعة داخل التطبيق:

- مكون مركزي: `PrintPreviewModal`.
- العرض يكون داخل التطبيق عبر iframe.
- الأزرار الموحدة: إغلاق، وطباعة / حفظ PDF.
- حفظ PDF يتم من نفس أمر الطباعة عبر خيار Save as PDF.

أول تطبيق فعلي للتجربة الجديدة:

- التقرير العام الجديد.
- تفاصيل مسير الرواتب: طباعة كشف المسير.
- تفاصيل مسير الرواتب: طباعة مسير توقيع لكل موظف.

المسارات التي ما زالت تستخدم `PrintPreviewModal` تعتبر موحدة الهوية فقط، وليست مكتملة تجربة المعاينة حتى يتم نقلها إلى `PrintPreviewModal`.
